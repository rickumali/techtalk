# Drupal to Eleventy

This project shows how I converted a small Drupal BLOG into
a statically generated site built by Eleventy. The core of the
work was guided by Claude AI. These were the high level steps
that I followed.

1. Survey content types
2. Write export scripts
3. Retrieve URL aliases
4. Copy `sites/default/files` (media files)
5. Convert JSON to content files
6. Pick a site generator (Eleventy)
7. Generate the site and iterate
